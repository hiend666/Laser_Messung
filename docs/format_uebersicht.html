⚠ Bekannte Einschränkung — TXT Hubmessung mit µs-Quellen: Die Merger-TXT schreibt den Zeitvektor stets mit dem Label Time (ms), speichert aber die Δt-Werte in der Einheit der Quelldatei. Wenn die Quelle eine Oszilloskop-CSV mit µs-Zeitbasis ist, erscheinen die Zeitwerte beim Re-Import als Hubmessung um den Faktor 1000 zu groß (z. B. 0,5 µs → 0,5 ms).
Workaround: Für Quellen im µs-Bereich stattdessen Oszilloskop CSV als Exportformat verwenden.
Import-Workflow je Format
CSV plain
  • ①Dateityp: CSV plain
  • ②Kopfzeilen überspringen: 0
  • ③Toggle "Kanalnamen aus Zeile 1" aktivieren
  • ④Abtastrate manuell eingeben
  • ⑤Einheiten je Kanal manuell wählen
TXT Hubmessung
  • ①Dateityp: Hubmessung
  • ②Zeitachse wird automatisch erkannt
  • ③Kanalnamen manuell setzen
  • ④Einheiten je Kanal manuell wählen
  • ⑤⚠ Nicht für µs-Quellen geeignet
Oszilloskop CSV
  • ①Dateityp: Oszilloskop CSV
  • ②Zeitachse + Einheit automatisch
  • ③Einheiten aus [Hinweis] im Dropdown manuell bestätigen
  • ④Kanalnamen manuell setzen
  • ⑤Empfohlen für µs-Daten
CSX (Vollständig)
  • ①Merger → Oszilloskop CSV exportieren
  • ②In Haupt-App laden, Kanäle konfigurieren
  • ③Export-Format: CSX wählen
  • ④Alle Einstellungen automatisch beim nächsten Laden
CSX wird nicht direkt vom Merger erzeugt. Der CSX-Export steht nur in der Haupt-App zur Verfügung (Seitenleiste → Export → Format: CSX). Er speichert alle EINSTELLUNGEN_KEYS inklusive der eingebetteten Messdaten. Ein CSX aus einem früheren Merge-Workflow (Merger → Oszilloskop CSV → Haupt-App → CSX) ist der einzige verlustfreie Rückweg.
